# Product

## Register

product

## Users

Vietnamese viewers and creators use User Web and Mobile; authorized staff use a separate Admin Web. Source: docs/features/Module_NguoiDung.md and Module_QuanTri.md.

## Product Purpose

HuTube is a shared video platform. S4-01/02 provides reliable registration, email verification, sign-in and session recovery across clients.

## Brand Personality

Clear, approachable, focused. Follow the supplied light, blue-accent interface references in docs/design/web_design1.png and mobile designs; retain the HuTube project name.

## Anti-references

Avoid decorative marketing layouts in authentication and administration; never display passwords or credentials (Module_NguoiDung.md).

## Design Principles

- Follow the supplied interface examples.
- Make the current authentication state and next action clear.
- Preserve the user's intended destination through login.
- Enforce access on the backend as required by PROJECT_ARCHITECTURE.md.

## Accessibility & Inclusion

Vietnamese copy; visible labels, keyboard access, readable contrast, responsive forms, and reduced-motion support. These are implementation defaults from impeccable, not additional user requirements.
