# Flow xuyên User và Admin dự kiến

Chưa có script cross-app. Dùng nhiều browser context: owner upload → reviewer claim/decision → User nhận notice → owner report/appeal → reviewer khác xử lý → watch/effective state. Thêm membership invitation, account lock/role revoke giữa phiên, plan payment sandbox và notification. Lưu chung resource IDs, chụp cả hai app ở cùng trạng thái nghiệp vụ. Actor cố định được seed một lần và tái sử dụng.
